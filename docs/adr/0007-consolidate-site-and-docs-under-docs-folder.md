# Move the public site into docs/, stop copying assets into it, drop the workshop archive from git

`flash-site/` needed everything GitHub Pages would serve to physically live inside it, since Pages publishes one directory as-is with no build step. That meant `deployConfiguratorAssets.ps1` copied BOM component photos, variant hero photos, and a subset of `3dFiles/` STLs into `flash-site/img/` and `flash-site/downloads/`, and every copy got committed to git alongside its source — doubling real binary content for no benefit. We're moving the site itself into `docs/` (its HTML/CSS/JS/firmware, previously `flash-site/*`) so it becomes a sibling of `docs/images/` and `docs/materials/` instead of a separate folder needing copies of them: the Configurator now links to `docs/images/components/...` and `docs/images/gallery/...` directly, and STL "download" links point straight at `raw.githubusercontent.com/BasementEngineering/MiniKenterprise/main/3dFiles/...` (an accepted pattern for occasional, user-initiated downloads, as opposed to images loaded on every page view, which stay served by Pages' own CDN). `deployConfiguratorAssets.ps1` now only rescans `3dFiles/` and regenerates the tiny `stl-manifest.json`; the Pages workflow (`path: docs`) needs no build step of its own. The site's public URL is unchanged, since `docs/index.html` still serves at the Pages root.

Existing images were reorganized into `docs/images/{components,gallery,build}/` — `components/` for BOM part photos (was `docs/materials/images/`), `gallery/` for "finished boat" inspiration photos (was root `images/*_Variant_*`, meant to grow substantially once a scrolling gallery ships on the site), and `build/` for everything else that used to live in the repo-root `images/` folder (hardware-version galleries, soldering tips, diagrams), moved wholesale. The repo-root `README.md`'s old step-by-step build walkthrough moved into `docs/build/BuildGuide.md` alongside those photos, leaving `README.md` a short entry point that links out to the guide and the site for BOM/3D files/flashing — the intent being that `docs/` grows into a one-stop shop (BOM with purchasing links, build steps, pinout for the recommended version, flashing) while the root README stays a lean front door.

Also folded in here: the old workshop presentation archive (`docs/workshop/`, several hundred MB of pptx/docx/pdf, never actually committed) moved to a gitignored top-level `workshop-archive/` — kept on disk, never pushed to GitHub, and no longer nested under whatever `docs/` publishes.
